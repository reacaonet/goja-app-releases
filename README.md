# GoJá Delivery — Releases dos Apps (APK)

Repositório **público** usado apenas para hospedar os arquivos **APK** dos apps Android do GoJá Delivery (Cliente e Entregador), para distribuição direta pela landpage durante a fase de testes.

> O código-fonte fica no repositório privado `reacaonet/toop-delivery`.

## Downloads

Os APKs são publicados automaticamente no release de tag **`mobile-apk`**:

- **Cliente (usuário):** https://github.com/reacaonet/goja-app-releases/releases/download/mobile-apk/goja-cliente.apk
- **Entregador:** https://github.com/reacaonet/goja-app-releases/releases/download/mobile-apk/goja-entregador.apk

## Instalação no Android

1. Baixe o APK desejado no link acima.
2. No aparelho, habilite **"Instalar de fontes desconhecidas"**.
3. Abra o arquivo baixado e confirme a instalação.

---

_APK de fase de testes (assinado com chave de debug). A versão para a Google Play será publicada separadamente._
